# codeonym docs

Documentation for the open-source projects of [codeonym-oss](https://github.com/codeonym-oss).

## Projects

[mediary](https://docs.codeonym.work/projects/mediary/)
: Typed, decorator-driven mediator + CQRS for Python — handlers, pipelines and notifications
  discovered by package scan. [PyPI](https://pypi.org/project/mediary/) ·
  [GitHub](https://github.com/codeonym-oss/mediary)

[jira-time-tracker](https://docs.codeonym.work/projects/jira-time-tracker/)
: `jtt`: how much estimated work (story points, hours, days…) came into being in a Jira Cloud
  project over a period, per issue and per person. [PyPI](https://pypi.org/project/jira-time-tracker/) ·
  [GitHub](https://github.com/codeonym-oss/jira-time-tracker)

[i18n-ai](https://docs.codeonym.work/projects/i18n-ai/)
: Generate a website's locales from its source locale tree, with LLM agents that keep every
  placeholder intact. [GitHub](https://github.com/codeonym-oss/i18n-ai)

[flow-reel](https://docs.codeonym.work/projects/flow-reel/)
: Turn a Playwright script into a narrated, polished demo video, the same way every time, with a plugin
  that teaches Claude Code and Codex to make them. [npm](https://www.npmjs.com/package/flow-reel) ·
  [GitHub](https://github.com/codeonym-oss/flow-reel)
